这一板块怎么用

  1. 这些是整批全转录稿（职场类 193 篇、法政讲坛 148 篇），与收藏夹那 232 篇观点/科普稿分开统计、分开筛选，不会混进收藏夹分支。

  3. 想搜这批内容：点上面任意来源卡片的「在文稿库中检索」，或直接用 transcripts.html#c=<来源key> 深链。

主动归档 · 3 篇

以后自动转录 / 自动整理出来的文稿，直接丢进 主动归档/ 目录即可

归档规则（约定俗成，照着放就行）

  1. 放什么：B 站视频转录整理稿、微信群聊/会议结构化总结、任何自己整理好的长文笔记。
  2. 放哪里：D:\PythonProject\MyDataTreasureWeb\主动归档\（可再建子文件夹，会递归扫描）。
  3. 什么格式：Markdown（.md）。文件名建议 标题_YYYYMMDD.md； 第一行用 # 标题，下一行加来源行（转录稿格式：【B站up主】xxx 【视频标题】[链接](链接)）。
  4. 怎么生效：放好后执行一次 python _build\build_portal.py（或告诉我「重建门户」）， 文稿即进入本页列表与全文检索；_归档说明.txt 里有完整说明。

本入口的生成方式

  1. 页面全部自包含：数据内联，不联网、不依赖 CDN，file:// 双击即可打开。
  2. 重建命令：python _build/build_portal.py（新增/修改节点后重跑即可）。
  3. 归档投放目录：主动归档/ —— 新转录 / 新整理的 .md 放这里，重跑生成器即自动收录。
  4. 图谱页面里带 Canvas 静态图谱 的两张需读 JSON，浏览器限制必须走本地服务 → 双击 启动本地服务.bat。

使用说明

四条路径，按需取用

① 新转录的稿子往哪放

  1. 把整理好的 .md 丢进 主动归档/ → 重跑 python _build/build_portal.py → 自动出现在首页「主动归档」与全文检索里。
  2. 首行写 # 标题；转录稿再加一行来源：【B站up主】xxx 【视频标题】[链接](链接)。
  3. 文件名建议 标题_YYYYMMDD.md，同名覆盖即更新。完整约定见 _归档说明.txt。

② 只想读文稿

  1. 打开 transcripts.html：左边列表 + 全文检索，右侧渲染完整整理稿（含概要、关键帧图说、概念实体）。
  2. 支持深链：transcripts.html#id=BV1fqJw6WEXC 直接定位某篇；#q=关键词 全文检索。
  3. 快捷键：/ 聚焦搜索、↑ ↓ 选条目、Esc 清空。

③ 想看图 / 找画面

  1. 打开 gallery.html：1331 张关键帧瀑布墙，可按库 / UP主 / 视频筛选。
  2. 点任意图放大，← → 翻页，可直接跳到对应文稿。

④ 想看观点如何连成网

  1. 打开 projects/bilibili-kb/graph/kb.html：Canvas 网图，支持语义检索、概念浏览器、拖拽钉住、关键帧灯箱。
  2. 用 #n=BV号 可从任何页面直达某个节点。
  3. 合并视图 kb_all.html 覆盖两个收藏夹（234 节点）。
